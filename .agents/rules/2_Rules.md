# Rules
## 1. Tech Stack Strictness
- Strictly React and Tailwind CSS v4 utility classes. No inline CSS or external stylesheets.
## 2. Glassmorphism Formula
- Elements must utilize: semi-transparent background (`bg-white/10`), backdrop blur (`backdrop-blur-md`), and subtle border (`border border-white/20`).
## 3. Accessibility First
- High contrast text against blurred backgrounds. No low-opacity white text for body copy.
## 4. Performance Optimization
- Limit heavy blur effects to key components. Utilize hardware acceleration.
